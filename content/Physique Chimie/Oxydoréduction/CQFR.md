## Couple d'oxydoréduction
$Mg^{2+}\text { (aq) / }Mg\text{ (s)}$ 
   |                   |
Oxydant         Réducteur

Oxydant : Espèce qui peut gagner des électrons
Réducteur : Espèce qui peut perdre des électrons

Les deux espèces d'un couple d'oxydoréduction sont liés par 1/2 équation électronique
$Mg_{\text{(s)}}=Mg^{2+}_{\text{(aq)}}+2e^-$ (Réducteur subit une oxydation) ou $Mg^{2+}_{\text{(aq)}}+2e^-=Mg_{\text{(s)}}$ (Oxydant subit une réduction)
Les deux sens sont possibles

## Réaction d'oxydoréduction
= Réaction au cours de laquelle des électrons sont échangés : ils passent d'une espèce à l'autre
=> Une réaction d'oxydoréduction fait l'oxydant d'un couple  (n°1) et le réducteur d'un autre couple (n°2)
Ex : couple $Mg^{2+}\text { (aq) / }Mg\text{ (s)}$ : $Mg_{\text{(s)}}=Mg^{2+}_{\text{(aq)}}+2e^-$ OXYDATION
couple $H^+\text { (aq) / }H_2\text { (g)}$ : $2H^+_{\text{(aq)}}+2e^-=H_2\text {(g)}$ REDUCTION
$Mg_{\text{(s)}}+2H^+_{\text{(aq)}}\text{->}Mg^{2+}_{\text{(aq)}}+H_{2\text{ (g)}}$
