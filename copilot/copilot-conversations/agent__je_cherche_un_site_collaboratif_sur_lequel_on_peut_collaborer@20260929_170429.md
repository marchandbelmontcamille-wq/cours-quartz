## Plateformes avec bots personnalisables

**Pour équipes / travail :**

- **Slack** — Le plus connu. Tu peux créer des bots via l'API Slack ou Bolt SDK (Python/JS). Très flexible, supporte les slash commands, les webhooks, les interactions UI.
- **Discord** — Très populaire, API puissante, bibliothèques comme `discord.py` ou `discord.js`. Parfait pour des communautés.
- **Microsoft Teams** — Bots via Azure Bot Framework. Plutôt en contexte scolaire/entreprise.

**Plus orientés développeurs :**

- **Mattermost** — Alternative open-source à Slack, hébergeable soi-même. API compatible avec les webhooks Slack.
- **Rocket.Chat** — Aussi open-source, tu peux héberger ton instance et créer des bots via leur SDK.

**Pour la collaboration sur documents :**

- **Notion** — API disponible, mais les bots sont plutôt des intégrations externes (pas de bots "natifs" dans l'interface).
