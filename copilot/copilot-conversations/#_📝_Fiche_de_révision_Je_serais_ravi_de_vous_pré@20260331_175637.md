## 🧬 Bilan S10-A : L'ADN

- Les êtres vivants possèdent une **information génétique** sous forme d'**ADN** (Acide DésoxyriboNucléique)
- L'ADN = molécule composée de **2 chaînes** enroulées en **double hélice**
- Chaque chaîne est constituée de **4 nucléotides** :
  - **A** = Adénine
  - **T** = Thymine
  - **C** = Cytosine
  - **G** = Guanine
- Les nucléotides sont **complémentaires 2 à 2** :
  - **A ↔ T** et **C ↔ G**
- ⚠️ **Toutes les cellules** d'un organisme possèdent **la même molécule d'ADN**

## 🔬 Bilan S10-B : Gènes, allèles et mutations

- Les **caractères** d'un individu sont définis par des **molécules produites par les cellules**
- L'info pour produire ces molécules = la **séquence nucléotidique** (ordre des nucléotides le long d'un brin d'ADN)
- Cette séquence est répartie sur **23 paires de chromosomes**
- La séquence est découpée en portions = les **gènes**
  - Chaque gène **code une molécule** → à l'origine d'un **caractère**
- Les gènes peuvent avoir des **versions différentes** = les **allèles**
  - Les allèles d'un même gène n'ont que **quelques différences** dans leur séquence → explique les différentes formes d'un même caractère
- Dans une espèce : **mêmes gènes**, mais **pas forcément les mêmes allèles**
- Dans une **paire de chromosomes** : les gènes sont les mêmes sur les 2 chromosomes, mais les **allèles peuvent être différents**
- **Mutation** = changement d'un ou plusieurs nucléotides dans la séquence d'un gène → crée un **nouvel allèle**

## 🌿 Bilan S11 : Évolution, sélection naturelle et spéciation

- **Spéciation** = quand 2 populations deviennent tellement différentes qu'elles **ne peuvent plus se reproduire** entre elles → **2 espèces différentes**
